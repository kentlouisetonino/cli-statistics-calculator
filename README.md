## Setup

> - Setup a virtual environment.

```sh
python3 -m venv venv
```

> - Activate the virtual environment.

```sh
source venv/bin/activate
```

> Install the packages.

```bash
pip3 install -r requirements.txt
```
> Run the programs.

```bash
# Run the re_scale.py program.
make main
```
